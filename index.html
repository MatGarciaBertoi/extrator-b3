🔒 Política de Privacidade

✅ Este aplicativo opera 100% localmente no seu navegador. Nenhum dado pessoal, financeiro ou arquivo é enviado a servidores, armazenado em disco ou compartilhado com terceiros.

1. Identificação do Controlador

Este produto é desenvolvido e mantido pela Bertoi Informática, responsável pelo tratamento de dados nos termos desta política.

2. Dados Tratados

O Extrator B3 processa, exclusivamente em memória RAM do seu dispositivo, os seguintes dados contidos nos PDFs de Nota de Corretagem:

  • Número e data da nota de corretagem
  • Dados de negociações (ativo, quantidade, preço, valor operação)
  • Taxas e encargos financeiros da nota

Esses dados nunca saem do seu dispositivo e são descartados automaticamente ao fechar ou recarregar a página.

3. Finalidade do Tratamento

Os dados são tratados com a única finalidade de gerar o arquivo Excel solicitado pelo próprio usuário, sem qualquer análise, perfilamento ou uso secundário.

4. Ausência de Armazenamento e Transmissão

Este aplicativo:

  • Não utiliza localStorage, sessionStorage, IndexedDB, cookies ou qualquer mecanismo de persistência
  • Não realiza requisições de rede com dados do usuário
  • Não integra SDKs de analytics, rastreamento ou publicidade
  • Não coleta endereço IP, identificadores de dispositivo ou metadados de uso

5. Base Legal (LGPD — Lei nº 13.709/2018)

O tratamento dos dados se baseia no legítimo interesse e consentimento do titular (art. 7º, II e IX da LGPD), uma vez que o próprio usuário fornece voluntariamente o arquivo e aciona o processamento. Não há coleta de dados sensíveis nos termos do art. 11 da LGPD.

6. Direitos do Titular

Como nenhum dado pessoal é armazenado, os direitos de acesso, correção, portabilidade e eliminação são satisfeitos de forma automática — ao encerrar o uso, todos os dados processados são descartados da memória.

7. Hospedagem e Logs de Acesso

Este aplicativo é disponibilizado por meio de infraestrutura de hospedagem estática (atualmente GitHub Pages, da GitHub Inc. / Microsoft Corp.). Ao acessar o site, o servidor de hospedagem registra automaticamente dados técnicos de conexão, incluindo:

  • Endereço IP do visitante
  • Data e hora do acesso
  • Tipo de navegador e sistema operacional (user-agent)
  • URL requisitada

Esses registros são coletados exclusivamente pela plataforma de hospedagem para fins de segurança e operação da infraestrutura, não sendo acessados ou utilizados pela Bertoi Informática. Consulte a Política de Privacidade do GitHub para informações sobre o tratamento desses dados.

O aplicativo em si não realiza nenhuma requisição de rede com dados do usuário após o carregamento inicial da página.

8. Segurança

O processamento local elimina os principais vetores de violação de dados em trânsito. O arquivo Excel gerado é entregue diretamente ao dispositivo do usuário, sem passar por intermediários. A conexão com o site é protegida por HTTPS/TLS provido pela plataforma de hospedagem.

9. Contato (Encarregado de Dados — DPO)

Para dúvidas sobre esta política ou sobre o tratamento de dados, entre em contato com a Bertoi Informática pelos canais oficiais disponíveis no site.

10. Atualizações desta Política

Esta política pode ser atualizada a qualquer tempo. A versão vigente estará sempre disponível nesta aplicação. Última atualização: maio de 2025.
